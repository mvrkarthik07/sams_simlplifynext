# M9 — AWS packaging (run last, after the backend is green)

## Objective
Deployable infrastructure with a hard cost fence. Nothing here changes application logic.

## Deliverables
1. `infra/` — CDK (TypeScript) in `us-east-1`:
   - DynamoDB single table, on-demand, PITR off, GSI1 as specified.
   - S3 buckets: `snapshots`, `preimages`, `audit` (Object Lock enabled at creation — it cannot
     be added later; this is a one-way door, get it right on the first synth).
   - Lambdas: connectors, drift engine, plan builder, executor, broker handler, budget guard.
     512 MB / 30 s defaults; ARM64; log retention 1 day.
   - Step Functions Standard state machine from `broker/statemachine.py`.
   - EventBridge Scheduler (hourly snapshot) + custom bus for HR events.
   - SSM Parameter Store SecureString for all connector credentials. **Not** Secrets Manager.
   - Lambda Function URLs. No API Gateway, no ALB, no VPC, no NAT.
   - Static SPA bucket wired to the existing `frontend/` build output. Do not modify `frontend/`;
     read its build script to find the output directory.
2. IAM: one least-privilege role per Lambda. The executor role is the only principal with
   `iam:DetachUserPolicy` / `iam:DeleteUserPolicy`, scoped by resource. No wildcard actions on
   `iam:*` anywhere — a governance tool with `AdministratorAccess` is the joke the judges make.
3. `infra/test/` — CDK assertions: banned constructs absent, log retention set, Object Lock on,
   no wildcard IAM. CI already greps for banned constructs; make the assertions the primary check.
4. Deploy runbook in `README.md`, including teardown. Teardown must be one command.

## Gate
`make gate-m9`
