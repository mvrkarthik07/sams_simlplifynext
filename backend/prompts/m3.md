# M3 — Plan builder, canonical encoding, plan hashing

## Objective
Turn findings into signed, hashable, reversible plans. The stage moment is running the engine
twice and showing identical plan hashes — that property is built here.

## Deliverables
1. `plan/canonical.py`
   - `canonical_dumps(obj) -> bytes`: `json.dumps(sort_keys=True, separators=(",",":"),
     ensure_ascii=True).encode("utf-8")`. Only `str|int|bool|None|list|dict` permitted;
     a `float` anywhere raises `TypeError` with the offending key path in the message.
   - `iso_second(dt) -> str`: tz-aware UTC only, `%Y-%m-%dT%H:%M:%SZ`. Naive input raises.
   - `plan_hash(body) -> str`: `sha256(canonical_dumps(body)).hexdigest()`.
2. `plan/builder.py`
   - `build(findings, evaluated_at, template_version) -> Plan`
   - `Plan` splits into `body` (hashed) and `envelope` (not hashed).
     - `body`: `schema_version`, `evaluated_at`, `template_version`, `weights_version`,
       `actions` — each action `{seq, system, resource, scope, verb, from_scope, to_scope,
       finding_id, score, tier}`.
     - `envelope`: `plan_id` (uuid4), `created_at`, `trace_id`, `attempt`.
   - Actions sorted by `(system, resource, scope)` as UTF-8 bytes, then `seq` assigned 0..n-1.
   - `verb` ∈ `{"revoke", "downgrade"}`. **There is no grant verb and no code path that can
     widen access** — assert this with a test that scans the action constructor for any
     transition where `to_scope` severity > `from_scope` severity and raises.
   - Pre-image slots are declared here and filled by the executor; a plan whose action lacks a
     `pre_image_key` cannot be executed.
3. `plan/preimage.py` — deterministic S3 key derivation:
   `preimages/{plan_hash}/{seq}-{sha256(resource|scope)[:16]}.json`.
4. Tests marked `m3` plus `determinism`, ≥98% coverage of `plan/`:
   - Same findings + same `evaluated_at` ⇒ identical `plan_hash`, different `plan_id`.
   - Reordering the input findings does not change `plan_hash`.
   - Golden hash committed to `tests/gates/golden/plan_hash_seed_a.txt`; the test compares
     against it. Changing this file requires a `DECISIONS.md` entry.
   - Float rejection test, naive-datetime rejection test, non-ASCII identity handled.
   - Widening attempt raises `PolicyViolationError`.

## Gate
`make gate-m3`
