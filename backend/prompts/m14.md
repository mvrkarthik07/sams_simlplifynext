# M14 — Authenticated live GitHub read path (POST-SUBMISSION ONLY)

Prerequisites, all mandatory before any code:
1. The submission is filed and tagged.
2. API and MCP Function URLs require a bearer token; anonymous access returns 401.
3. The PAT lives in SSM Parameter Store SecureString (never Secrets Manager, per AGENTS §4.5),
   read at invocation with a least-privilege execution-role policy scoped to that one parameter.
4. The PAT is fine-grained, read-only, single-org, with an expiry inside the hackathon window.
5. A separate end-to-end rehearsal is recorded before the endpoint is shown to anyone.

Scope: a `snapshot` route that calls the real GitHub provider read-only and writes to the graph
store. No write path to GitHub. Rate-limit handling and pagination already exist in the provider
— reuse, do not reimplement. If any prerequisite is unmet, stop and record why.
