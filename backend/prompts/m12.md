# M12 — Product surface: provenance, determinism proof, dead-end removal

## Objective
Make every visible control functional and every data row honest about its origin.

## Owner exception
DECISIONS.md grants component edits for this milestone, bounded to: presentation, provenance
labelling, empty/loading/error states, and the plan-hash panel. Forbidden: changes to routing,
state management, data shapes, or the `api.ts` operation signatures.

## In scope
1. **Provenance badges.** Every finding row and detail view shows its source:
   `Live` (captured from a real system, with `captured_at` on hover), `Simulated` (fixture).
   Legend visible on the findings page. A judge must never have to ask which is which.
2. **Determinism panel.** PRD §7 step 6. On the plan view, show `plan_hash`. `rerunDriftEngine`
   displays previous and current hash side by side with an explicit equal/not-equal verdict,
   and shows that `plan_id` differs while the hash matches.
3. **Dead ends.** Inventory every interactive element. Anything that no-ops, renders a
   placeholder, or is unreachable from the findings page gets hidden behind a build flag
   (default off). Write the inventory to `backend/artifacts/ui-inventory.md` — element,
   verdict, action taken.
4. **States.** Loading skeletons, empty states with a next action, and error states that show
   the error envelope's `code`/`message` and a retry. No spinner that can hang forever; no
   blank screen on a failed fetch.
5. **Evaluation clock.** If the UI renders scores, show `evaluated_at` and the `as_of` offset
   in the header. The offset is disclosed, never hidden.

## Out of scope
New pages, new routes, a design-system swap, animation libraries, dark mode, any new npm
dependency, any backend change beyond a field already in the contract schema.

## Constraints
- Zero new runtime dependencies. Use what is already in `package.json`.
- Copy is plain and specific. No marketing adjectives in the UI.
- `npm run lint`, `npm run typecheck`, `npm run build` all pass.

## Acceptance gate
    gate-m12:
    	cd frontend && npm run lint && npm run typecheck && npm run build
    	cd backend && $(MAKE) verify && ./scripts/guard_protected.sh
    	test -s backend/artifacts/ui-inventory.md

Manual check the agent must perform and report: click every visible control on every reachable
screen; zero no-ops.
