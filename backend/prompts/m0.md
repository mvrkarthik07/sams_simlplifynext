# M0 — Scaffold, tooling, frozen contracts

## Objective
Stand up the backend package, the toolchain, the test taxonomy, and the frozen
`EntitlementProvider` contract. Nothing in later milestones may proceed until the contract is
stable, because every other module codes against it.

## Deliverables
1. `backend/pyproject.toml` — `uv`-managed, Python 3.12, package `deadbolt` under `src/`.
   - runtime: `boto3`, `structlog`, `httpx`, `pydantic>=2`
   - dev: `pytest`, `pytest-cov`, `pytest-randomly`, `mypy`, `ruff`, `moto[iam,s3,dynamodb,stepfunctions]`, `respx`, `import-linter`, `freezegun`
   - `[tool.pytest.ini_options] markers = ["m0","m1","m2","m3","m4","m5","m6","m7","m8","m9","determinism","rollback","e2e","live"]`
   - `[tool.ruff]` line-length 100, select `E,F,I,N,UP,B,S,DTZ,PL,RUF`; `DTZ` is mandatory
     (bans naive datetimes)
   - `[tool.mypy] strict = true`, `disallow_any_explicit = true` for `deadbolt.engine` and
     `deadbolt.plan`
2. `backend/importlinter.ini` with these contracts:
   - `deadbolt.engine` and `deadbolt.plan` are **forbidden** from importing:
     `deadbolt.providers`, `deadbolt.graph`, `deadbolt.executor`, `deadbolt.audit`,
     `boto3`, `httpx`, `random`, `time`, `math`
   - layered contract: `handlers > executor > broker > plan > engine > contracts`
3. `backend/src/deadbolt/contracts/` — the frozen surface:
   - `Entitlement` (frozen, slots) exactly as PRD §4.3, with `last_used_at: datetime | None`
     tz-aware, and `raw: Mapping[str, object]` (immutable view, not `dict`)
   - `CredentialType`, `Scope`, `Tier` as `StrEnum`
   - `ActionResult(frozen)`: `ok: bool`, `system: str`, `resource: str`, `scope: str`,
     `dry_run: bool`, `pre_image: Mapping[str, object] | None`, `message: str`,
     `provider_latency_ms: int`
   - `EntitlementProvider(Protocol)`: `system: str`, `snapshot()`, `revoke(e, dry_run)`,
     `restore(pre_image)`. `restore` is mandatory — a provider without it cannot be onboarded.
   - `Clock(Protocol)` with `now() -> datetime`, plus `FixedClock` for tests
   - `deadbolt/errors.py`: `DeadboltError` base, `ProviderError`, `IrreversibleActionError`,
     `PolicyViolationError`, `IdempotencyConflict`
   - `contracts/export.py`: `python -m deadbolt.contracts.export --out DIR` writes JSON Schema
     for every public dataclass. CI diffs this; it is how frontend/backend drift is caught.
4. `backend/tests/unit/test_contracts.py` marked `m0`: assert every dataclass is frozen and
   slotted, every datetime field rejects naive datetimes, and `EntitlementProvider` is
   `runtime_checkable` with a compliance test helper
   `tests/support/provider_compliance.py::assert_provider_contract(p)` that later milestones
   reuse for all six providers.
5. `DECISIONS.md` with the header and one seed entry.
6. `.gitignore`, `.agent/` ignored.

## Constraints
- Zero AWS calls. Zero network. `boto3` may be imported but no client constructed at module scope.
- `frontend/` untouched.

## Gate
`make gate-m0`
