# M2 — Drift engine: pure scoring, tiers, break-glass

## Objective
The decision core. No I/O, no clock, no floats. This is the module that answers
"why is this not a custom GPT with subagents", so it must be provably deterministic.

## Deliverables
1. `engine/scoring.py`
   - All factors are integers in basis points, `0..10000`.
   - `scope_severity(scope) -> int` from a static catalog:
     `read=1000, write=5000, admin=9000, billing|secrets|iam=10000`. Unknown scope raises.
   - `dormancy(last_used_at, evaluated_at) -> int`:
     `clamp(floor(10000 * days_since / 90), 0, 10000)`; `None` (never observed) ⇒ `10000`.
     `days_since` computed from a whole-second timedelta; negative ⇒ `0`.
   - `role_mismatch(entitlement, template) -> int`: `10000` or `0`. Binary, no partial credit.
   - `blast_radius(n_reachable) -> int`: `clamp(floor(10000 * log10(1+n) / 4), 0, 10000)`,
     computed with `decimal.Decimal` inside
     `localcontext(prec=28, rounding=ROUND_HALF_EVEN)` using `Decimal.ln()` ratios.
     **`math.log10` is banned** — import-linter must fail if `math` is imported here.
   - `risk(s, d, m, b, weights) -> int`: `(40*s + 25*d + 20*m + 15*b) // 100`, weights loaded
     from a config dict so a security admin can retune without redeploy. Weights must sum to
     100; otherwise raise `PolicyViolationError`.
2. `engine/tiers.py`
   - Thresholds in basis points: `T0 < 3000`, `T1 3000..5999`, `T2 6000..8499`, `T3 >= 8500`.
   - `select_tier(score, identity) -> Tier`. Break-glass is applied **after** scoring and
     **before** tier assignment: `oncall=True`, membership in a protected group, or an active
     incident tag forces any `T1` to `T2`. Hard-coded, not scored, not overridable by config.
     Test that a config change cannot defeat break-glass.
3. `engine/drift.py`
   - `detect(entitlements, identities, templates, reachability, evaluated_at) -> tuple[Finding, ...]`
   - Pure function. Returns a tuple sorted by `(-score, system, resource, scope)`.
   - Each `Finding` carries the full score decomposition (`s`, `d`, `m`, `b`, `score`, `tier`)
     plus an `evidence` mapping — the demo shows the decomposition, not just the number.
   - A non-revocable entitlement produces a `T0` observe-only finding, never an action.
4. Tests marked `m2`, ≥98% coverage of `engine/`:
   - Table-driven boundary tests on every threshold: 2999/3000, 5999/6000, 8499/8500.
   - Property tests: score is monotone non-decreasing in each factor; score ∈ `[0, 10000]`;
     `detect` is idempotent and order-independent in its inputs (shuffle input, same output).
   - `@pytest.mark.determinism` test: 100 runs of `detect` over the same seed produce the
     identical tuple, executed under `-p no:randomly`.
   - A test asserting `engine/` imports nothing from `providers`, `graph`, `boto3`, `time`,
     `random`, `math`.
