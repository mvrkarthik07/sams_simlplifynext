# M6 — Approval broker: Step Functions, Slack card, bounded LLM

## Objective
Human decision brokering with safe timeout semantics in both directions, and an LLM confined to
prose and re-planning — never to the revoke decision.

## Deliverables
1. `broker/statemachine.py` — Step Functions **Standard** ASL (Express lacks
   `waitForTaskToken`), generated as JSON and snapshot-tested:
   - `NotifyApprover` → `.waitForTaskToken` with heartbeat, no polling
   - timeout branches per tier: `T1` proceeds after the 72 h objection window; `T2` escalates to
     the security admin at 24 h and takes **no action**; `T3` pages and takes no action.
   - Encode the asymmetry as data, not `if` statements: a `TIER_TIMEOUT_POLICY` table with an
     explicit `on_timeout: "proceed" | "escalate" | "page"` per tier, unit-tested against the
     tier enum for exhaustiveness.
2. `broker/card.py` — pure Slack Block Kit builder. Four actions:
   `Approve` · `Reduce further` · `Keep, with reason` · `Defer 30 days`.
   Evidence rendered from the finding decomposition: days since last use, template version it is
   absent from, blast-radius count. Snapshot-test the JSON payload.
3. `broker/negotiate.py` — the only LLM in the path, LangGraph node in Lambda, Bedrock
   `us-east-1`.
   - `Reduce further` ⇒ the model proposes a tighter scope **selected from a closed set of
     scopes present in the entitlement graph**. The returned scope is validated against that set
     and against severity monotonicity; anything else is rejected and the node re-plans
     deterministically to the next-lowest scope. Test with an adversarial mocked model that
     returns a wider scope, an unknown scope, prose, and malformed JSON — all four must be
     rejected without widening.
   - `Keep, with reason` ⇒ drafts a template-amendment candidate. Writes a proposal record;
     never mutates the ratified template.
   - Model choice: Nova Lite for classification/summarization, Claude Haiku for prose. Both
     behind a `LLMClient` Protocol so tests inject a fake and CI makes zero Bedrock calls.
4. `broker/handler.py` — Slack interactivity endpoint on a Lambda Function URL:
   verify `X-Slack-Signature` (HMAC SHA-256 over `v0:{ts}:{body}`), reject timestamps older
   than 300 s, then `SendTaskSuccess` with the decision. Signature verification has its own
   negative tests.
5. Tests marked `m6` using `moto` Step Functions and a fake Slack. Assert every branch writes an
   audit record including approver identity, plan hash, and trace id — including the branches
   where the system declined to act.

## Gate
`make gate-m6`
