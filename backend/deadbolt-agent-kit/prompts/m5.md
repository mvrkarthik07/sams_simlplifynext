# M5 — Tier A real connectors: AWS IAM and GitHub

## Objective
The credibility anchor. Real read surfaces, real revoke, real restore. Tested against `moto`
(IAM) and `respx` (GitHub) in CI; validated against the sandbox only in `-m live` runs that CI
never executes.

## Deliverables
1. `providers/aws_iam.py`
   - Read: `ListUsers`, `ListAttachedUserPolicies`, `ListUserPolicies`,
     `GetServiceLastAccessedDetails` (generate + poll job, with a bounded poll and a cached
     result — Access Advisor is the genuine `last_used_at` source and it is asynchronous).
   - Map service-last-accessed timestamps onto entitlements; unmapped ⇒ `last_used_at=None`.
   - Write: `DetachUserPolicy` (managed) and `DeleteUserPolicy` (inline).
   - Pre-image: for inline policies the full `GetUserPolicy` document; for managed, the policy
     ARN plus attachment metadata.
   - `restore`: `AttachUserPolicy` / `PutUserPolicy` from the pre-image, then verify.
   - `dry_run=True` uses `SimulatePrincipalPolicy` where the action is expressible, otherwise
     returns a validated no-op result. It must never mutate.
   - Handle `NoSuchEntity` as an already-revoked success (idempotent), not an error.
2. `providers/github.py`
   - Read: `GET /orgs/{org}/members`, `GET /repos/{owner}/{repo}/collaborators` (with
     `permission` field), `GET /user` on a fine-grained PAT for token scope + `last_used_at`.
   - Write: `DELETE /repos/{owner}/{repo}/collaborators/{user}` for revoke;
     `PUT .../collaborators/{user}` with `{"permission": "..."}` for downgrade and for restore.
   - Respect `X-RateLimit-Remaining`; back off with jitter; surface `ProviderError` with the
     reset timestamp rather than retrying forever.
   - Pagination via `Link` headers, fully consumed.
3. Both providers pass `assert_provider_contract` from M0 unchanged.
4. `tests/live/test_sandbox_iam.py` marked `live` — a real revoke+restore against a
   throwaway IAM user. Never runs in CI. Document the exact command in `README.md`.
5. Add a `--dry-run` CLI: `python -m deadbolt.cli snapshot|detect|plan|execute|rollback`,
   because the demo and the rehearsal both need a terminal path that does not depend on the SPA.

## Notes for the agent
- If `iam:CreateUser` is denied by the sandbox permission boundary, fall back to operating on
  inline policies of the existing user and record that in `DECISIONS.md`. Do not block on it.
- Verify every endpoint exists before building on it. If a write path is unavailable on the free
  tier, degrade that system to a fixture provider and log the degradation — do not fake it.
